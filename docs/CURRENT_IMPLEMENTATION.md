## 2. 処理の流れ

```text
GLB を読む → 三角形(ワールド座標)に展開 → BVH 構築
  各ピクセルに、N 本(`--spp`)のカメラレイを発射(既定 N = 1、ピクセル中心。`--jitter` でピクセル内のランダムな位置)
    trace(ray, depth):
      最近傍の交点を探す(BVH)
      光源の上の点を1つ選ぶ(面光源モード)
      材質に応じて: 直接照明(拡散 + スペキュラ + 影) + 反射 + 屈折
      反射・屈折は再帰(最大 depth 6)
  色(線形) → Film に蓄積 ─────────────── ここまでが「計算」
  Film → 露出 → クランプ → ガンマ(1/2.2) → 8bit → 画面 / PNG / PPM   ← 「表示変換」(Display)
  Film → そのまま PFM(線形の浮動小数)
```

## 3. シーン(GLB)の読み込み

| 対応している | 対応していない / 未確認 |
|---|---|
| GLB(バイナリ)の JSON + BIN チャンク | 外部ファイルや data URI のバッファ |
| 三角形メッシュ(mode 4)、インデックス 8/16/32bit | 三角形以外のプリミティブ(読み飛ばす) |
| 頂点位置・法線(法線がなければ面法線)、**`TEXCOORD_0`(UV、float のみ)** | 頂点カラー、2組目以降の UV、normalized 整数の UV |
| ノードの変換(translation / rotation / scale / matrix)、子ノード | スキニング、アニメーション |
| 材質: `baseColorFactor`、`metallicFactor`、`roughnessFactor`、`KHR_materials_transmission`、`KHR_materials_ior`、`KHR_materials_specular`(`specularFactor` だけ)の係数。Path の PBR が全部使う。Classic が使うのは、transmission と roughness / metallic の一部で、屈折率は1.5固定。**テクスチャ(M8 の1歩目): `baseColorTexture`(sRGB。`baseColorFactor` に掛ける)と `metallicRoughnessTexture`(G = roughness、B = metalness。`roughnessFactor` / `metallicFactor` に掛ける)。埋め込みの PNG だけ**。Classic も Path も使う | クリアコート、発光、**法線マップ、occlusion、emissive テクスチャ**、`transmissionTexture` などの他のテクスチャ、JPEG・外部ファイル・data URI の画像、サンプラー(ラップ・フィルタ。常に repeat + 双線形)、`KHR_texture_transform`、`texCoord` が 0 以外、ミップマップ(縮小時のちらつきの対策なし)、`specularColorFactor`、volume(減衰・厚み) |
| カメラ: シーン内の最初の透視カメラ | 正射影カメラ、複数カメラの切り替え |
| 面光源(矩形): ノードの extras(`rt_light_type` = "rect"、`rt_size_x`、`rt_size_y`、`rt_radiance`)と、ノードの変換。描画に使う(M1) | ライト(`KHR_lights_punctual`)。Blender のエリアライト自体は GLB に出力されないので、Blender のカスタムプロパティで補っている |

- **テクスチャ**(2026-10-17、M8 の1歩目): `src/png_decode.h` の自前 PNG デコーダ(inflate: 非圧縮・固定・動的 Huffman、フィルタ 5 種、8/16 ビット、グレー / RGB / RGBA / パレット。**インターレースは未対応**。Adler-32 と CRC は検証しない。出力は 8 ビット RGB)で、glb に埋め込んだ PNG を読む。画像は、同じものを共有するテクスチャで 1 回だけ復号する。メモリは 8 ビット RGB(4096x6144 で約 75 MB)。`Texture::sample` は双線形で、v は下向き(glTF)、ラップは repeat、sRGB は**混ぜる前に**線形へ変換する。UV は三角形ごとに持ち(`Triangle::uv`)、ヒットで補間する(`Hit::tu/tv`)。すべての材質の参照は `materialAt()` を通り、テクスチャがなければ scene の材質をそのまま返す(コピーなし)ので、**テクスチャのない glb の画像は変わらない**(Cornell・MaterialRow・Room_2Spheres・Untitled で、修正前のバイナリと PFM がバイト単位で同一)。`--no-textures`(GUI にもチェックボックス)で、係数だけの描画に戻せる。**UDIM は glTF にないので、Blender のエクスポートで 1 枚のアトラスにまとめる**(`tools/export_beetle_room_textured.py`)。
- **Blender から書き出すときの注意**: 面光源のノードを glb に出すには、エクスポータの `export_lights=True`(ライトを含める。「未対応の AREA」という警告は出るが、ノードと extras は書かれる)が必要。オフだと光源がなく、画面は**真っ黒**になる(2026-10-16 に実際に起きた)。`export_extras=True` と `export_cameras=True` も使う。テクスチャは `baseColor` と `metallicRoughness` だけ読む(UDIM は不可。`tools/export_beetle_room_textured.py` はアトラスにまとめる)。テクスチャを使わず係数だけにしたいときは、材質を単色に置き換えて書き出す(`tools/export_beetle_room.py`)。
- 座標系は glTF(Y 上、右手系)。Blender(Z 上)からの変換はエクスポータが行う。
- 法線はワールド座標へ変換して使う(逆転置行列の余因子で計算)。
- `doubleSided`(材質): 既定では**参照せず、すべての面を両面として扱う**(これまでのすべての画像)。**`--cull-backfaces`**(GUI にもチェックボックス)をオンにすると、`doubleSided = false` の材質の三角形は、**裏側から当たるレイ(カメラ、反射、屈折、影のすべて)には存在しない**ものとして扱う。表は、これまでどおり当たる。表裏は glTF の規約どおり、**頂点の巻き順(反時計回りが表)**で決める(法線の向きではない)。ローダは `doubleSided` を読み、**ファイルに書かれていなければ glTF の既定の false** とする(Blender のエクスポータは、マテリアルの「Backface Culling」がオンなら false、オフなら true を書く)。使い道: 壁を、部屋の内側からは見えて、外側からは消える面にして、カメラを壁の外に置く(`Scene/Test/Beetle_Room.glb`)。**制約**: ノードの変換が反転(負のスケール)を含むとき、glTF は巻き順を逆にするよう定めているが、**未対応**。Cornell.glb と MaterialRow.glb は `doubleSided` を持たない(= false)ので、**このスイッチをオンにすると画像が変わる**(オフなら変わらない)。

## 4. カメラ

- ピンホールカメラ。既定は1ピクセル1サンプル(ピクセル中心)で、アンチエイリアスなし。`--jitter --spp N` で、ピクセル内の一様ランダムな位置に N サンプルを置く(アンチエイリアス)。
- GLB のカメラがあれば使う。16:9 の横方向の視野を保ったまま、4:3 の画面に映す(縦方向は少し狭くなる)。
- カメラがなければ、コード内の固定カメラ(`makeCamera()`)を使う。

## 5. 光源

光源のモデルは2つあり、切り替えられる(`--light point|area`、パネルの「light」)。**既定は面光源(area)**。

**面光源(area、M1)**
- 矩形1個。GLB のノード(名前 `Area_Light`)と、Blender のカスタムプロパティ(glTF の extras に出る)から読む。
  - プロパティ: `rt_light_type`(= "rect")、`rt_size_x`、`rt_size_y`(m)、`rt_radiance`(放射輝度、レンダラ内の単位)。Blender 側のライト設定(大きさ・ワット数)も合わせてあるが、レンダラは読まない。
  - 規約: 矩形はノードのローカル X・Y 軸に広がり、**ローカル -Z 方向に発光**する(glTF のカメラやライトと同じ。Blender のエクスポータが、ライトのオブジェクトをこの向きで書き出す)。
  - 現在の値: 2 m × 2 m(面積 4)、`rt_radiance` = 11.56、中心 (-4, 5, 2)、発光の向き (0.667, -0.667, -0.333)(部屋の中心に向けて斜め下)。
- **サンプリング**: 影を調べたい点ごとに、矩形の上の一様ランダムな点を1つ選び(`sampleLight()`)、そこへシャドウレイを飛ばす。乱数は、そのサンプルの `Sampler` から取る。
- **重み**: `放射輝度 × 面積 × cos(光源側の角度) ÷ 距離²`(= 放射輝度 × cos ÷ 距離² ÷ PDF、PDF = 1/面積)。点での `cos(N·L)` は、従来のシェーディングの式の中。**距離の2乗に反比例して暗くなる**。発光は片面のみ(光源の裏側には光が出ない)。
- **較正**: `rt_radiance` は、部屋の中心の床 (0, 0, 0) で、矩形全体の平均が、旧点光源(色 1)と同じ明るさ(重み 1.0)になる値(平均 0.977 を 1.0 に合わせて 11.3 → 11.56)。ただし、距離減衰が入るので、他の場所の明るさは旧点光源と違う。
- **大きさの変更**: `--light-size METRES` / パネルの「light size」で、正方形の一辺を変えられる(中心は同じ)。**総電力(放射輝度 × 面積)は一定**に保つので、大きさを変えると、影のやわらかさだけが変わり、全体の明るさは変わらない。0 = GLB のとおり(2 m)。
- 面光源の幾何は、描画には出さない(カメラから光源そのものは見えない)。

**点光源(point、M0 の基準)**
- 点光源1個(位置は面光源の中心 (-4, 5, 2)、色 (1, 1, 1))。**距離減衰なし**、影は硬い。乱数を一切使わない。M0 の基準画像とビット単位で同一(確認済み)。

**共通**
- 環境光は一定値 0.12(`ambient`)を、拡散色に掛けて加える。物理的な根拠のない補正項。
- 背景(どのオブジェクトにも当たらないレイ): 空色のグラデーション(ブレンダーのワールド設定とは無関係)。

## 6. 交差判定と高速化

- 三角形: Möller–Trumbore 法、両面。独立した関数 `intersectTriangle()` にしてある(線(直線)との交差を返し、`t > EPS` と最近傍の判定は呼び出し側 `Scene::intersect` が行う)。
- **三角形の探し方**(`--accel none|median|sah`、パネルの「triangle search」。**既定は SAH**。どれも同じヒットを返す。画像は完全に同じ):
  - `none`: 全三角形を調べる(基準。小さいシーン用)。
  - `median`: BVH、中央値分割(重心の最も長い軸で `nth_element`)、葉は最大4三角形。
  - `sah`: BVH、binned SAH(重心を16ビンに分け、「箱の表面積 × 個数」を使ったコストが最小の分割を選ぶ。3軸を試す。分割しても得にならず、4個以下なら葉)。
  - BVH の深さに上限 56(走査のスタックが64)。構築時間は JSON の `acceleration.bvh_build_ms`(ビートルで、中央値 約 70 ms、SAH 約 180 ms)。
- **近い子から走査**(`--no-ordered` で切る。既定オン): ノードを開くときに、2つの子の箱との交点の距離を計算し、近い子を先に調べる。これまでに見つかった最近傍より遠い箱は、飛ばす。ノード訪問数は、「箱を調べた回数」として数える。
- **any-hit の影レイ**(Path のみ、`--no-any-hit` で切る。既定オン): `Scene::occluded()`。最初の交差で打ち切る。Classic の影レイは、ガラスを通す(透過率を掛ける)ので、最近傍を使う。
- 最近傍の探索は、`Scene::intersect()`。
- 補間した頂点法線を、シェーディング法線に使う。**表裏(レイが三角形の表から当たったか、裏か)は、三角形そのものの向き(幾何法線 `Hit::ng`、頂点法線の側に向ける)で判定**し、裏なら法線を反転する。補間した法線が、輪郭の近くでカメラと反対向きになる場合は、カメラ側にほぼ接線(cos = 0.01)になるように補正する。旧方式(`--legacy-normals`)は、補間した法線で判定して反転する(輪郭で、反射・屈折のレイが球の内側に入る不具合があった)。
- スレッドごとのカウンタ(`Stats`)で、レイ数(`Scene::intersect` の呼び出し)、BVH ノードの訪問数、三角形の判定数を数える。
- 自己交差を避けるため、二次レイの原点を法線方向に 1e-3 ずらす(`EPS * 10`)。

## 7. シェーディング(`trace()`)

材質の値は glTF の仕様どおり、linear な値として扱う。

**直接照明(`transmission < 1` の面)**
- 拡散: `baseColor × (1 − metallic) × (1 − transmission) × 光 × max(0, N·L)`。
- スペキュラ: Blinn-Phong。指数は roughness から `2 / roughness⁴ − 2`(上限2000)。反射率 f0 は `lerp(0.04, baseColor, metallic)`。強さの係数 `(指数 + 8) / 25` は見た目の調整で、**エネルギー保存の裏付けはない**。
- 光: 面光源モードでは、ヒットごとに光源上の1点をランダムに選び、`光 = 重み(上の5章)× 影の透過率`。点光源モードでは、光源の色 × 影の透過率(従来どおり)。面光源の1サンプルは、ピクセルのサンプル(`--spp`)ごとに別の点になるので、**サンプル数を増やすと半影が滑らかになる**(ジッタなしでも)。
- 影: 光源へのシャドウレイ。不透明な物体で遮られたら光なし。ガラスは遮らずに通過し、`baseColor × 0.9 × transmission` を掛ける(簡易処理。屈折による光の曲がりは考慮しない)。

**反射**
- `roughness < 0.5` の不透明な面だけ、完全鏡面の反射レイを追加する。重みは フレネル(Schlick、f0 は上と同じ) × `(1 − roughness)`。
- roughness が0.5以上の面には、反射を追加しない(つやのぼやけた反射は表現しない)。

**ガラス(`transmission > 0`)**
- フレネル(Schlick、f0 = 0.04)で、反射と屈折の重みを決める。屈折率1.5固定。全反射を処理する。屈折光には `baseColor × transmission` を掛ける。
- スペキュラのハイライト(指数800)を直接光に加える。面光源では、ランダムな点からのハイライトなので、サンプルが少ないとざらつく。

**再帰**: 反射・屈折ともに最大6回。打ち切り時は、直接照明の分だけを返す。

## 8. 色と出力

- シェーディングは線形の浮動小数で行う。
- **`Film`**: 画素ごとに「線形の合計」と「サンプル数」を持つ。`pixel()` は平均(線形のまま)を返す。1 を超える値も保持する。既定は1ピクセル1サンプルなので平均は計算値そのもの。`--spp N` では N サンプルの平均になる(合計と個数を持つので、足し合わせる順序が決まっていれば、結果は再現する)。
- **`Display`**(表示変換): 露出(線形の係数、既定 1.0)→ クランプ → `pow(c, 1/2.2)` → 8bit。厳密な sRGB 式ではなく、トーンマッピングもない(クランプのみ)。画面・PNG・PPM の変換に使う。表示を変えても、再計算は不要。
- 保存形式: PPM(8bit)、PNG(8bit、無圧縮)、PFM(32bit 浮動小数、線形。HDR 比較用)。
- **乱数**: PCG32。**(シード, ピクセル番号, サンプル番号)** ごとに独立した列(`Sampler`)を作る(種は SplitMix64 で混ぜる)。乱数の状態をスレッド間で共有せず、1ピクセルのサンプルは決まった順に足すので、**結果はスレッド数や描画の順序に依存しない**(スレッド数 1・5・7 で、ビット単位で同一になることをテストで確認済み)。
- **乱数を使う場所**: ピクセル内のランダムな位置(`--jitter`)と、面光源のサンプリング(既定の光源モード)。点光源モードで、ジッタなしなら、乱数を一切消費せず、シードにも影響されない(`--light point --legacy-normals` で、M0 の基準画像とビット単位で同一になることを確認済み)。
- 最大反射回数は実行時の設定(`Scene::maxDepth`、既定6)。
- `trace()` は `Sampler` を受け取り、面光源のサンプリング(`sampleLight()`)が、その乱数を使う。
- film 導入前後で、出力画像(8bit)はビット単位で同一であることを確認済み(2シーン)。

## 8a. プログレッシブ描画(M3)

- `RenderParams::progressive`(`--progressive` / `--no-progressive`、パネルのチェック)。**ウィンドウの既定はオン、画面なしの既定はオフ**。
- 1ピクセルあたりの総サンプル数を **1 → 4 → 16 → 64 → …(4倍ずつ)** と増やし、最後のパスが目標の `spp` にちょうど届く(`nextPassTotal()`)。各パスの終わりに、`RenderJob` が画像(平均)を公開し、ウィンドウが表示を更新する。途中の画像は、その時点までの全サンプルの平均。
- **再現性**: サンプル番号 `0, 1, 2, …` はパスをまたいで通し番号(`RenderSettings::firstSample`)。1ピクセルのサンプルは、いつも同じ順で足されるので、パスの分け方によらず、フィルムは**ビット単位で同一**(テストで確認。段階描画と一括描画の PNG も同一)。
- **追加**: 完了した描画に「**+ samples**」で N spp を足せる(`RenderJob::extend()`)。何もリセットしない。キャンセルした後は、ピクセルごとのサンプル数が不揃いなので、追加できない。
- **リセット**: パネルの設定(ジッタ、シード、スレッド数、反射回数、光源、光源サイズ、積分方式、NEE、空の光、輪郭の方式、プログレッシブ)を変えると、蓄積を捨てて描き直す(パネルの「restart when a setting changes」で切り替えられる)。サンプル数の目標とシーンのパスは、Render / + samples で反映。カメラ・材質はパネルに無いので、シーンを変えたときだけ。
- 画面なし: `--progressive --out PREFIX` で、各パスの後に `PREFIX_sppN.png` を保存する。
- 進捗: パネルの Status に `done / target spp` とパス数。

## 8b. パストレーシング(M2、`--integrator path`)

`pathTrace()`(`src/raytracer.h`)。Classic の `trace()` とは別の経路で、直接照明のコードは使わない(二重計上なし)。

- **材質**(`--bsdf lambert`、この章の説明。**既定の PBR は 8c 章**): すべて Lambert 拡散。アルベド = `baseColor`。metallic、roughness、transmission(鏡・ガラス)は**無視する**(Room_2Spheres の金属球・ガラス球も拡散球になる)。
- **経路**: カメラ → 交点 → コサイン重み付き半球サンプリング(PDF = cos/π)で次の方向 → …。`BSDF × cos / PDF` はアルベドになり、スループットに掛ける。
- **発光**: 面光源は三角形ではないので、`intersectAreaLight()` で別に交差判定する(発光面=表側のみ。裏側は見えない。光源は不透明で、手前の三角形に隠される)。光に当たったら `スループット × 放射輝度` を足して終わる。カメラから光源そのものも見える。
- **環境光**: 何にも当たらなかったレイは、空のグラデーション × `--env`(既定 0 = 面光源だけが光る)。
- **反射回数**: `--max-depth`(パネルの max bounces)= 追跡する反射の回数。0 = 光源が直接見えるだけ、1 = 直接照明(BSDF サンプリングのみ)、…。ロシアンルーレットなし(回数ごとの比較のため)。打ち切った分は戻らないので、わずかに暗めになる。
- **MIS(既定オン、`--no-mis` で NEE のみ)**: NEE の寄与に、BSDF サンプリングとの Power Heuristic の重み(`pdfLight² / (pdfLight² + pdfBsdf²)`)を掛け、BSDF サンプリングの経路が光源に当たったときの寄与に、反対の重み(`pdfBsdf² / (pdfBsdf² + pdfLight²)`)を掛けて足す。密度は、どちらも立体角あたり(`bsdfPdfLambert()` = cos/π、`lightPdfSolidAngle()` = 距離² / (面積 × cos(光源側)))。カメラレイが光源を直接見るときは、重みなし。BSDF のみ(`--no-nee`)/ NEE / MIS の期待値は、反射回数の上限ごとに一致する(テスト)。Cornell Box で、大きい光源(1.5 m)では NEE より約 20% 低ノイズ、小さい光源では同じ(`experiments/2026-10-15_m4-mis/`)。
- **Russian Roulette(`--rr`、既定オフ)**: 3回反射から、生存確率 p = スループットの最大成分を [0.05, 0.95] に制限、続ける経路は 1/p 倍、そうでなければ打ち切り。期待値は変わらない(平均輝度の差 0.01% 以下)。`--max-depth` は上限として残る。レイ数は半分(`experiments/2026-10-15_m4-russian-roulette/`)。
- **NEE(既定オン、`--no-nee` でオフ)**: 各反射点で、光源の上の一様ランダムな点(PDF = 1/面積)にシャドウレイを飛ばし、`アルベド/π × 放射輝度 × cos(面) × cos(光源) × 面積 ÷ 距離²` を足す(`sampleDirectLight()`)。シャドウレイは、すべてのものが完全に遮る(ガラスも)。BSDF サンプリングの経路が光源に当たっても足さない(二重計上の回避。カメラレイが光源を直接見るときだけ足す)。反射回数の上限ごとに、NEE なしと同じ期待値になる。Cornell Box で、同じ spp の誤差は約 1/4、同じ画質なら約 10 倍速い(`experiments/2026-10-15_m4-nee/`)。オフにすると、小さい光源ではノイズが大きい。MIS(BSDF 側との組み合わせ)は未実装。
- 環境光の定数 `ambient` は使わない。乱数は Classic と同じ `Sampler`(スレッド数に依存しない)。
- 検証(`tests/test_main.cpp`、NEE の一致・ノイズも): コサイン分布の平均、光源の片面・範囲、巨大光源の下の床の解析解(ρ·Le)、反射回数での単調増加、色移り、スレッド数への非依存。
- **Cornell Box**: `Scene/Test/Cornell.glb`(`tools/make_cornell.py` で生成。光源 0.5 m、放射輝度 15)。実験は `experiments/2026-10-15_m2-cornell/`。

## 8c. PBR の材質(M7、`--bsdf pbr`)

`--bsdf lambert|pbr`(パネルの「surface model」)。**Lambert** は 8b のとおり(M2 の実験を、ビット単位で再現する)。**PBR** がアプリの既定(`Scene` の既定は Lambert で、`RenderParams` が PBR を指定する)。Classic 方式は、この設定の対象外。

**材質(glTF の metallic-roughness)**: `base`、`metallic`、`roughness`、`transmission`、`ior`(`KHR_materials_ior`、既定 1.5)、`specular`(`KHR_materials_specular` の `specularFactor`、既定 1)。

**不透明な面**(`PbrBsdf`、局所座標で法線 = +z):
```text
f = 拡散色 × (1 − Es(μo)) (1 − Es(μi)) / (π (1 − Ē))                 拡散(Es: 鏡面ローブの方向アルベド)
  + F(wo·h) D(h) G2 / (4 cosθo cosθi)                                 GGX の鏡面(単一散乱)
  + Fms (1 − E(μo)) (1 − E(μi)) / (π (1 − Ē_E))                       多重散乱(Kulla–Conty)
```
- 拡散色 = `base × (1 − metallic)`。F は Schlick: `F = f0 + (f90 − f0)(1 − wo·h)^5`、`f0 = mix(((ior−1)/(ior+1))² × specular, base, metallic)`、`f90 = mix(specular, 1, metallic)`。alpha = roughness²。
- D = GGX(Trowbridge–Reitz)。G2 = height-correlated Smith。
- **Es(μ)**(方向アルベド)は、`SpecularAlbedoLut`(μ 24 × roughness 24 の2つの表 A, B。`Es = f0·A + f90·B`)で引く。起動後の最初の使用時に作る(Release で約0.1秒、見える法線の層化サンプル 48×48)。拡散の重みを `(1−Es(μo))(1−Es(μi))/(π(1−Ē))` にすると、拡散のアルベドがちょうど `1 − Es(μo)` になり、鏡面と合わせて 1 を超えない。glTF 仕様どおりの `(1−F(v·h))×拡散 + 鏡面` は、グレージング角で方向アルベドが 1.4 まで上がった(数値積分)ので使わない。
- **多重散乱**(`--no-multiscatter` で切る): 単一散乱の GGX は、粗い金属で roughness 0.5 / 0.75 / 1.0 で 11% / 35% / 61% のエネルギーを失う(白い炉)。`E(μ) = A + B`(F = 1 のときのアルベド)、`Favg = f0 + (f90−f0)/21`、`Fms = Favg² Ē_E / (1 − Favg(1 − Ē_E))` の余弦ローブを足す。拡散と同じ方法でサンプルする。
- **サンプリング**: 鏡面ローブを確率 `pSpec`(鏡面と拡散 + 多重散乱のアルベドの比、[0.05, 0.95] に制限)で選ぶ。鏡面は見える法線のサンプリング(VNDF、Heitz 2018)、PDF = `G1(wo) D(h) / (4 cosθo)`。拡散は余弦サンプリング。PDF は2つの混合(選択確率を含む)。重み = `f cosθi / pdf`。
- **鏡**(alpha < 1e-3、つまり roughness < 0.032): delta ローブ。確率 `pSpec` で選び、重み = `F(cosθo) / pSpec`。`eval()` / `pdf()` は、delta でないローブだけ。roughness 0.05 は、鋭いが delta ではない。

**ガラス**(`transmission > 0`): 確率 = transmission で、滑らかな誘電体として扱う(それ以外は不透明な面)。厳密な Fresnel(偏光なし)の確率で反射し、そうでなければ屈折する(`refractDirection`、全反射を処理)。屈折の寄与に base color を掛け、放射輝度を `(n_i/n_t)²` 倍する(入るときと出るときで打ち消し合う)。表裏は、幾何法線で決める(閉じた立体を仮定)。**粗いガラス(つや消し)は未対応で、滑らかなガラスとして扱う。**

**光源サンプリングと delta**: 鏡・ガラスの後は、delta なので、光源サンプリングをしない(`prevDelta`)。その後に光源に当たったら、重み 1 で足す(M4 の残りだった、delta 成分での MIS の分岐)。delta でないローブでは、これまでの MIS(混合 PDF とのパワーヒューリスティック)。ガラスは、影の判定では不透明な遮蔽物なので、**ガラス越しの光は、BSDF サンプリングだけが拾う**(コースティクスはざらつく)。
- 反射回数の上限は、ガラスの境界ごとに1回数える(球を通るのに2回)。ガラスを描くときは、`--max-depth` を大きめにする。
- **Blender Cycles との比較**(`experiments/2026-10-16_m7-cycles/`、別プロセスの画面なし Blender 5.2、同じ光源・空・カメラ、1024 spp): 球ごとの比は、鋭い金属(roughness 0.5 以下)と鏡が 1.000〜1.003、粗い金(0.75、1.0)が 1.026 と 1.047、プラスチックが 1.023〜1.050、ガラスが 1.020〜1.033(このレンダラーのほうが明るい)。原因は未解決(鏡面を厳密な Fresnel にしても縮まらなかった)。
- 白い炉(`--env-uniform 1`): 鏡 0.9996、ガラス 1.0000、金属(roughness 0.1〜1.0)0.998〜1.003、プラスチック 0.9987〜0.9999(`experiments/2026-10-16_m7-furnace/`)。
- 検証(`tests/test_main.cpp`): フレネル、GGX の正規化・シャドウイング、VNDF の PDF が確率に一致、サンプリングの重みが数値積分と一致して 1 を超えない、全角度でのアルベド(プラスチック < 1.005)、相反性、材質のパラメータ(ローブの選択)、glTF の `ior` / `specular` の読み込み、白い炉(ガラス・鏡・粗い面・多重散乱)、スネルの法則、ガラス板越しの光のずれと減衰、鏡越しの光源、3方式の期待値の一致(光沢面・ガラス越し)、スレッド数への非依存。

## 9. 既知の制約・近似

- Classic 方式の光輸送は、直接照明と、鏡面反射・屈折だけ(環境光の定数で間接光を代用)。拡散面どうしの間接光は、Path 方式だけが持つ(上の 8b 章)。Path 方式の材質は、Lambert(M2)または PBR(M7、8c章)。PBR の制約: 粗いガラス(つや消し)は未対応、ガラスの影は完全な影(ガラス越しの光は BSDF サンプリングだけが拾い、コースティクスはざらつく)、ガラスの色(base color)は境界を通るたびに掛かる(体積の減衰ではない)、発光・クリアコート・法線マップなしの glTF の一部、空の光は光源サンプリングの対象外。
- 実験の描画時間のうち、M2・M3・NEE の実験(2026-10-15)の当時の記録は Debug の値。Release で測り直した値は `experiments/2026-10-16_release-timings/`(Debug の約 18〜26 倍速い)。
- 光源は面光源(矩形)1個のみ。1つの点につき、光源のサンプルは1つ(サンプルを増やす手段は、ピクセルのサンプル数だけ)。光源側と BSDF 側のサンプルを組み合わせる MIS は未実装(M4)。
- 面光源の明るさの較正は、部屋の中心の1点での平均。距離減衰が入っているので、旧点光源の画像とは、全体が異なる(RMSE 0.27、基準の面光源画像との比較)。
- 輪郭(シルエット)の挙動は、近似が残る(下の6章)。補正の値(cos = 0.01)は、経験的で未調整。
- (修正済み)金属球・ガラス球の輪郭に出ていた真っ黒な点(旧方式で、1 spp で2球のシーンは 14 / 30万ピクセル)は、表裏の判定を三角形の向きに変えて解消した。旧方式は `--legacy-normals` で再現できる。詳細は `experiments/2026-10-15_silhouette-fix/notes.md`。
- ガラスの影・コースティクスは、簡易的なもの(コースティクスは出ない)。
- 既定ではアンチエイリアスがなく、輪郭にジャギーが出る(`--jitter --spp N` で解消)。
- 屈折率は固定。クリアコートなどの材質拡張は読まない。
