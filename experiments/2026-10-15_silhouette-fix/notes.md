# 2026-10-15 silhouette-fix (輪郭の黒い点の修正)

金属球・ガラス球の輪郭に出ていた真っ黒な点(M0 の基準画像から含まれていた不具合)の修正と、その効果。

## 不具合の仕組み

1. 三角形メッシュの球は、平らな三角形に、滑らかな頂点法線を補間して使う。輪郭の近くでは、三角形はカメラを向いているのに、補間した法線がカメラと反対向きになることがある。
2. 旧コードは、表裏を「補間した法線がレイと同じ向きか」で判定して、法線を反転していた。
3. そのため、反射・屈折のレイが球の**内側**に向かい、内側で跳ね返り続け、最大反射回数で打ち切られて 0 になった(金属は拡散反射がないので、真っ黒)。

## 修正

- **表裏は、三角形そのものの向き(幾何法線)で判定する。** 幾何法線は、頂点の巻き方向ではなく、頂点法線の側に向ける(`Hit::ng`)。
- 補間した法線がカメラと反対向きなら、カメラ側にほぼ接線(cos = 0.01)になるように補正する。
- 旧方式は `--legacy-normals`(パネルの「legacy silhouette normals (M0)」)で残した。M0 の基準画像と、過去の実験(面光源、アンチエイリアス、光源の大きさ)は、このスイッチでビット単位で再現できる(確認済み。それらの `run.sh` に、スイッチを付けた)。

## 再生成

```sh
sh experiments/2026-10-15_silhouette-fix/run.sh                    # 約40秒
python3 -I experiments/2026-10-15_silhouette-fix/analyze.py         # results.txt、before_after.png
```

## 観察

- 1 spp では、変わるのは 21 ピクセルだけで、真っ黒な点が消えた。他のピクセルは、1ビットも変わらない(輪郭から遠い所は、旧方式と同じ結果)。
- **64 spp(ジッタあり)では、黒い点は見えなくなっていたが、欠陥は消えていなかった**: 旧方式で、輪郭のピクセル 459個が、わずかに暗かった(最大 0.086、0.1 を超えるものはない)。修正で、その分が明るくなった。サンプルごとの欠陥が、平均で薄まって見えなくなっていただけ。
- 変わったピクセルの値(1 spp)は、周囲と調和している(0.05〜0.6)。たとえば、床の反射、壁の反射、ガラスの屈折。
- 輪郭の、わずかな別の変化(旧 0.6 → 新 0.16 などの大きな差)は、旧方式が球の内側の暗い反射を拾っていた箇所とみられる。

## 限界

- 補正の cos = 0.01 は、経験的な値(未調整)。値を変えたときの影響は、測っていない。
- 輪郭の反射・屈折は、補正した法線に基づく近似で、物理的に正しい値ではない(三角形メッシュの滑らかな法線を使う限り、輪郭の挙動には、近似が残る)。
- 修正の対象は、球の輪郭の表裏判定のみ。ほかの形状(複雑なメッシュ)での確認は、していない。
