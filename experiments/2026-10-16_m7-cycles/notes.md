# M7: Blender(Cycles)との比較

`run.sh` で再生成する(別プロセスの画面なし Blender 5.2 を使う。開いている Blender には触れない)。`tools/cycles_render.py` が、同じシーン(`Scene/Test/MaterialRow.glb`)を Cycles で描く:
glTF インポータの Principled BSDF(base color・metallic・roughness・transmission・IOR・specular)、面光源は発光する矩形(強さ = `rt_radiance` = 7、放射輝度が同じ数値)、
空はこのレンダラーの `background()` と同じグラデーション × 0.5、カメラは glb のもの、640x480、ボックスフィルタ(幅 1)、デノイズなし、反射回数 6、1024 spp。
このレンダラー側は `experiments/2026-10-16_m7-materials/pbr_1024spp`(PBR、MIS、多重散乱あり、反射回数 6、空の光 0.5)。
`python3 experiments/analyze_m7_cycles.py` が、球ごとの中心部(半径の半分の円)の平均 RGB の比を出す。

| 球 | このレンダラー / Cycles(RGB の平均) |
|---|---|
| 金 roughness 0.05 / 0.1 / 0.2 / 0.35 / 0.5 | 1.003 / 1.002 / 1.002 / 1.001 / 1.000 |
| 金 roughness 0.75 / 1.0 | 1.026 / 1.047 |
| プラスチック roughness 0.05 / 0.1 / 0.2 / 0.35 / 0.5 / 0.75 / 1.0 | 1.023 / 1.036 / 1.044 / 1.050 / 1.044 / 1.035 / 1.024 |
| ガラス IOR 1.2 / 1.5 / 2.4 | 1.020 / 1.032 / 1.033 |
| 鏡 / グレーの鏡 | 1.002 / 1.002 |

- **鋭い金属(roughness 0.5 以下)と鏡は、0.3% 以内で一致**。roughness → alpha(= roughness²)の対応、金属の色(F0 = base color)、鏡の Fresnel、面光源と空の較正が、Blender と合っていることの確認。
  金の色(R, G, B の比)も、全 roughness で 0.1〜0.3% 以内で一致している(ガラス・鏡の屈折や映り込みを含む)。
- 粗い金(0.75、1.0)は +3〜5%、プラスチックは +2〜5%、ガラスは +2〜3% 明るい。同じシーンの背景の領域は、床の手前 +0.6%、壁 +2.5%、ガラス球の下の床(集光する場所)+4.7%。
- **確認した仮説と結果**:
  - 「Blender の非金属の鏡面は、Schlick ではなく厳密な Fresnel だから、プラスチックが違う」: 鏡面を厳密な Fresnel にして描き直すと、差は縮まらず、わずかに増えた(roughness 0.2 で +5.6% → +5.8%)。**この仮説は外れ**。
  - 他の候補(未確認): 拡散と鏡面の結合の違い(このレンダラーは Es(μ) の表による結合、Blender は層の重ねの近似)、粗い金での多重散乱の補正の式の違い(Kulla–Conty の変種)、ガラスの集光(コースティクス)や反射回数の数え方の違い。
- 結論: 材質のパラメータの対応は、Blender と合っている(鋭い金属・鏡は 0.3% 以内)。数 % の差が残る原因は、**未解決**。
