# M2・M3・NEE の実験の描画時間を、Release で測り直したもの

2026-10-15 の実験の時間は Debug ビルドの値だった。同じ設定を、Release ビルド・既定の探索方式(SAH)で測り直した(1回ずつ、±10% の誤差)。
`run.sh` で再生成し、`python3 experiments/analyze_timings.py experiments/2026-10-16_release-timings` で表を作る。画像は、以前と同じ。

| 描画 | Debug [s] | Release [s] | 倍率 |
|---|---|---|---|
| M2 classic、16 spp | 3.37 | 0.18 | 19× |
| M2 パス(NEE なし)、256 spp、0回反射 | 28.3 | 1.45 | 19× |
| 同 1回反射 | 81.6 | 3.29 | 25× |
| 同 2回反射 | 103.2 | 4.78 | 22× |
| 同 4回反射 | 126.9 | 6.93 | 18× |
| 同 8回反射 | 181.9 | 9.93 | 18× |
| NEE、8回反射、256 spp | 274.3 | 13.6 | 20× |
| NEE なし、8回反射、256 spp | 183.4 | 9.67 | 19× |
| M3 段階描画 256 spp(NEE) | 286.3 | 13.5 | 21× |
| M3 一括 256 spp(NEE) | 345.6 | 13.5 | 26× |

- Release は、Debug の約 18〜26 倍速い(最適化と、BVH の SAH・近い子からの走査の合計。BVH だけの効果は、`2026-10-16_m5-accel`)。
- NEE は、NEE なしの約 1.4 倍の時間(Debug のときの約 1.5 倍とほぼ同じ)。
- 段階描画のパスの完了時刻(累積、Release): 1 spp 0.05 s、4 spp 0.22 s、16 spp 0.85 s、64 spp 3.39 s、256 spp 13.53 s。
- 段階描画と一括描画の時間は、Release では同じ(13.5 s)。Debug での差(286 s と 346 s)の原因は、未確認(当時、別のプロセスが動いていた可能性がある。M5 の実験の最中に、ユーザー側で起動したままのウィンドウが見つかった例がある)。
