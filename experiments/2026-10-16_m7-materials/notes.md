# M7: 材質の球列、PBR と Lambert、つやのある面でのサンプリング

`run.sh` で再生成し(Release)、`python3 experiments/analyze_m7.py experiments/2026-10-16_m7-materials`(`regions.json` の3つの列で集計)で `results.txt` を作る。
シーンは `Scene/Test/MaterialRow.glb`(`tools/make_material_row.py`): 奥の列 = 金(金属)、中の列 = 赤いプラスチック(非金属)、どちらも roughness 0.05〜1.0 の7個。
手前の列 = ガラス球(IOR 1.2 / 1.5 / 2.4)、鏡、グレーの鏡。ジッタ、シード 1、反射回数の上限 6、空の光 0.5(空は光源サンプリングの対象外)。

## つやのある面での光源サンプリングと BSDF サンプリング(基準 = PBR・MIS・4096 spp・シード 99 との RMSE)

| 方式 | spp | 全体 | 金属の列 | プラスチックの列 | ガラス + 鏡の列 |
|---|---|---|---|---|---|
| BSDF のみ | 64 | 0.0728 | 0.0687 | 0.0721 | 0.0815 |
| 光源サンプリング(NEE)のみ | 64 | 0.0692 | **0.2197** | 0.0579 | 0.0452 |
| NEE + MIS | 64 | **0.0217** | **0.0264** | **0.0202** | **0.0392** |
| BSDF のみ | 256 | 0.0364 | 0.0346 | 0.0359 | 0.0406 |
| NEE のみ | 256 | 0.0529 | 0.1746 | 0.0262 | 0.0225 |
| NEE + MIS | 256 | **0.0107** | **0.0129** | **0.0104** | 0.0187 |

- **鋭い金属では、NEE のみが最悪**(鏡のような反射のローブは細く、光源への方向を選んでも、BSDF の値が、ほとんど 0 のため)。BSDF サンプリングは、そこでは安定している。
- **プラスチック(拡散が主)では、BSDF のみが劣る**(光源に当たる確率が低い)。
- **MIS は、どの列でも最良**。全体では、BSDF のみの約 1/3.4、NEE のみの約 1/5(256 spp)。M4 で「つやのある面で MIS の本領が出るはず」としていた予想が、確かめられた。
- 基準画像が MIS なので、MIS にわずかに有利な可能性がある(基準は別シード、4096 spp)。3方式の期待値の一致は、テストで確認している。
- ガラスの列は、光源サンプリングでは(ガラスを不透明な遮蔽物として扱うので)、ガラス越しの光を拾えず、BSDF サンプリングだけが拾う(コースティクスは、ざらつく)。

## 多重散乱の補正の有無(MIS 1024 spp、領域の平均 RGB)

| 領域 | 補正あり | 補正なし | 比(R) |
|---|---|---|---|
| 金属の列 | 0.226 / 0.178 / 0.120 | 0.189 / 0.157 / 0.115 | 1.20 |
| プラスチックの列 | 0.278 / 0.088 / 0.094 | 0.276 / 0.087 / 0.094 | 1.01 |
| ガラス + 鏡の列 | 0.254 / 0.253 / 0.296 | 0.254 / 0.252 / 0.295 | 1.00 |

補正は、粗い金属だけを明るくする(金属の列の平均で約 20%。roughness 1.0 の球では、約 2.5 倍)。他の材質は、ほぼ変わらない。
