# M7: 白い炉(エネルギー保存の確認)

`run.sh` で再生成(`furnace.cpp` をビルドして実行し、`results.json` を作る)。一様な放射輝度 1 の環境の中に、材質1つの球を置き(光源なし、吸収なし)、
球の上の平均の放射輝度を測る。エネルギーを保存し、増やしもしないモデルなら、**1**になる。Release ビルド、反射回数の上限 40、球の円盤上の20万本のカメラレイ。

| 材質(白) | 多重散乱の補正なし | あり |
|---|---|---|
| 完全な鏡 | 0.9996 | - |
| ガラス(IOR 1.5、滑らか) | 1.0000 | - |
| ガラス(IOR 1.9、滑らか) | 1.0000 | - |
| 金属 roughness 0.10 | 0.9996 | 0.9993 |
| 金属 roughness 0.20 | 0.9966 | 0.9978 |
| 金属 roughness 0.35 | 0.9704 | 1.0026 |
| 金属 roughness 0.50 | 0.8920 | 0.9995 |
| 金属 roughness 0.75 | 0.6501 | 0.9980 |
| 金属 roughness 1.00 | 0.3915 | 0.9980 |
| プラスチック roughness 0.1〜1.0 | 0.9987〜0.9999 | 同じ |

- **滑らかなガラス・鏡は、ほぼ厳密に 1**(Fresnel の確率で反射 / 屈折を選び、屈折の放射輝度の補正 η² が、入るときと出るときで打ち消し合う)。
- **単一散乱の GGX は、粗い金属でエネルギーを失う**(roughness 0.5 で 11%、0.75 で 35%、1.0 で 61%)。マイクロファセットの間で2回以上反射する光が、数えられないため。
  **多重散乱の補正**(Kulla–Conty)で、すべての roughness で 1 に戻る(0.998〜1.003)。
- プラスチック(拡散 + 鏡面)は、補正の有無によらず 1 に近い(0.9987〜0.9999)。拡散と鏡面の結合を、鏡面ローブの方向アルベドで行っているため(RENDERING_GUIDE の第12章)。
  glTF 仕様どおりの `(1 − F(v·h)) × 拡散 + 鏡面` は、グレージング角で方向アルベドが **1.4** まで上がった(roughness 0.2、84°、数値積分)ので、使わなかった。
