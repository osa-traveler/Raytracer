# ノイズを減らす 3 つのスイッチ(間接光のクランプ、光沢面のぼかし、ガラスの影)の効果

- 日付: 2026-10-17
- シーン・条件: ビートルの 1 枚目(前方の斜め。`experiments/2026-10-17_beetle-views/`)。Path、PBR、NEE + MIS、RR あり、`--cull-backfaces`、256 spp、最大反射 8、シード 1、640x480、Release。基準 = 同じ構図の既定(スイッチなし)の 1024 spp(`reference_1024spp_default.pfm`。それ自体にもノイズが残る)。`run.sh` で再現(5 通り)。`default.*` は、スイッチなしの 256 spp。
- **最初の実行の誤り**: シェルが変数を単語に分割しない(zsh)ことに気づかず、オプションが渡らないまま 5 通りを描いてしまった(ファイル名にオプションが入っていて気づいた)。誤った出力は消し、`run.sh`(オプションを明示)で描き直した。

## 読み取り(推測を含む)
- **ガラスの影が、このシーンでは最も効いた**: 壁の粒 0.98% → 0.04%、フロントガラス 8.26% → 1.09%。平均の明るさはほぼ変わらない(フロントガラスの領域だけ +1.6%: 車内に光が直接届くようになったため)。**床と壁の白い粒の主な原因は、ガラス(大きな球と窓)を通る光だった**(最初の見立ての「塗装の反射」は、このシーンでは主因ではなかった。光沢面のぼかしの効果が小さいことと整合する)。
- **クランプ**: 粒はほぼ消えるが、**明るさが下がる(フロントガラス領域で −14%、壁・床・ボンネットで −2〜3%)**。値が小さいほど、強く下がる。ボンネットの RMSE は、偏りのために、既定より悪化した(0.0157 → 0.0288)。このシーンの光源の放射輝度は 11.56 で、上限 3 は強すぎる。
- **光沢面のぼかし 0.3**: このシーンでは効果が小さい(壁 0.98% → 0.96%、床 1.12% → 0.73%)。ボンネットの RMSE は悪化(0.0157 → 0.0208)。合成のテスト(平らな床 + ほぼ鏡の球 + 小さい光源)では、標準誤差が 0.27〜0.39 倍に下がり、平均は 3% 以内(`variance_probe.cpp` で測定。`tests/test_main.cpp` にも、標準誤差が 0.6 倍未満になる確認がある)。**効くかどうかは、シーンに、ほぼ鏡の面を経由する間接光があるかによる**。
- ガラスの影の**限界**: 薄く平らなガラス向け。ガラス球のような厚いガラスでは、屈折を無視した直進の近似になり、コースティクスは出ない(球の影は、色のついた薄い影になる)。この画像では、左端の大きな球の見え方に、目立った変化は見られなかった(目視)。
- 目視(`docs/screenshots/2026-10-17_noise-reduction-comparison.png`): ガラスの影で、壁・床・フロントガラスの内側がなめらかになり、車内がはっきり見える。3 つ併用がいちばんきれい。クランプ 3 は、粒は減るが、ボンネットが少し暗い。
- 未検証: 1024 spp の基準自体のノイズ(RMSE に含まれる)。他の構図・シーンでの効果。デノイザーとの比較。

## 「薄いガラスだけ」にした版(`rt_thin_glass`、`glass_thin_only.*`)
- きっかけ: ユーザーが、ガラス球の影が明るすぎる(影レイが球を素通りする)ので、ガラスの影をオフにしていた。窓ガラスだけを例外にしたい。→ 材質のカスタムプロパティ `rt_thin_glass = 1` を、窓の材質 `Vitre` に付け(Blender で追加。glb の extras に出ることを確認)、**印のある材質だけ**、影レイが通るようにした。印のないガラス(球)は、スイッチをオンにしても、オフと画像が同じ(テスト)。
- 描画: 1 枚目の構図、256 spp、`--glass-shadows` のみ(クランプなし、光沢面のぼかしなし)。`default`(オフ)、`glass`(最初の版: すべてのガラスが対象)と比べた(輝度。目で選んだ領域):

| 領域 | オフ | 最初の版(全ガラス) | 新(窓だけ) |
|---|---|---|---|
| フロントガラスの内側 | 平均 ×1.000、粒 8.26% | ×1.016、粒 1.09% | ×1.012、粒 **1.14%** |
| ガラス球 + 周りの床 | ×1.000、粒 1.59% | ×0.998、粒 0.76% | ×1.000、粒 1.23% |
| 床(右下) | 粒 1.12% | 粒 0.48% | 粒 1.09% |
| 壁(緑) | 粒 0.98% | 粒 0.04% | 粒 0.76% |
| 球の近く(左下の隅 x 0–40、y 440–480)の明るさ | ×1.00 | **×1.16**(影が明るすぎる) | **×1.00**(オフと同じ) |

- **読み取り**: 窓の内側の改善は、最初の版と同じ(1.14% ≈ 1.09%)。**球の影は、オフと同じに戻った**(左下の隅 ×1.16 → ×1.00)。代わりに、**壁と床の粒は、最初の版ほどは減らない**(壁 0.76%、床 1.09%)。これは、壁と床の粒の主な原因が、窓ではなく、**ガラス球を通る光**だったことを示す(前の見立て「ガラス(球と窓)」のうち、球が大きい)。
- 描画時間: 113.5 s(1 回)。**参考にならない**: 測定中、マシンの負荷が非常に高かった(ロードアベレージ約 45。システムの別プロセスが CPU を使っていた)。同じ条件で測り直した 64 spp の `--repeat 2` では、オフ 12.2 s、オン 12.9〜13.1 s(約 +6%)。この日の他の測定より、全体に約 30% 遅い(負荷のため)。
- 未検証: 5 枚すべてを、薄いガラスだけのオンで描き直すこと。クランプとの組み合わせでの明るさ。
